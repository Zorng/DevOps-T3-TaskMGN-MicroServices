# Identity & Workspace Scaffold Scope

This task establishes the Python/FastAPI application, service-owned PostgreSQL database and migration tooling, health endpoints, shared request/error handling, structured logging, metrics, automated tests, container setup, and CI verification.

The follow-up [Google sign-in and application-session task](google-signin.md) implements challenge/exchange/logout/current-user routes and migration `0002_google_sessions`. The [workspace task](workspace-management.md) implements list/create/read/rename/delete, initial owner memberships, shared invitation storage, the ten-owned limit, idempotency, ETags and transactional deletion events in migration `0003_workspace_management`. [Membership permissions](membership-permissions.md) adds listing/search, owner removal, non-owner leave, shared join/snapshot primitives and generation-specific events, with migration `0004_membership_generations` protecting immutable history. [Registered-user invitations](registered-user-invitations.md) adds all invitation endpoints, atomic capacity-checked acceptance, creation events and migration `0005_registered_invitations`. [Private access APIs](private-access-apis.md) now wrap live session and workspace checks with per-service keys and caller allowlists, without another migration. Public-gateway exposure proof and broker/consumer delivery remain integration tasks.

Status: planning, dependency setup, configuration, application lifecycle, PostgreSQL Compose, migrations, outbox storage, health endpoints, shared HTTP handling, structured logs/private metrics, unit/request/database integration tests, the service container, and the CI workflow are implemented. Hosted GitHub verification and actual registry publishing remain unverified; local checks do not establish a passing remote pipeline.
